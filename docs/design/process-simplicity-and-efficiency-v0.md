# Process Simplicity and Efficiency v0
## Normative rule

For equal guarantees use minimum sufficient process. CI is a verification boundary. Reuse unchanged state; aggregate independent blockers; automate mechanics, not authority.

## Current state only; Git owns history

Active artifacts, docs, registries and agent context contain **only current, useful truth**. Delete obsolete, invalid, replaced or duplicate entries/files. No `RETIRED`, `LEGACY`, tombstones, history lists or archives "just in case"; Git retains prior versions. Do not load old evidence unless relevant to the task. Before deletion, reconcile accepted downstream references or report a real blocker; never fake CURRENT. Retain otherwise obsolete data only for an explicit external audit or active reproducibility obligation, not speculation.
